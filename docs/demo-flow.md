# Hive Studio Demo Flow

Короткий сценарий демонстрации курсового проекта.

## Подготовка

1. Запустить `PostgreSQL`
2. Убедиться, что база `hive_studio` существует
3. Запустить сервер:

```bash
cd /Users/matthew/AndroidStudioProjects/kurs/hive-studio-server
./gradlew run
```

4. Запустить Android-клиент на эмуляторе

## Сценарий показа

### 1. Публичный каталог

- открыть вкладку `Каталог`
- показать все биты разных продюсеров
- показать поиск
- показать фильтры по жанру и цене
- показать сортировку

### 2. Авторизация

- открыть вкладку `Профиль`
- перейти на отдельный экран `Вход / Регистрация`
- выполнить вход
- вернуться в `Профиль`

### 3. Профиль продюсера

- показать сценическое имя
- показать аватар
- показать город, контакт и описание
- показать сводные показатели:
  - количество битов
  - суммарные прослушивания
  - суммарная выручка

### 4. Создание бита

- из профиля нажать `Добавить бит`
- выбрать `mp3`
- выбрать квадратную обложку
- заполнить данные
- загрузить бит

### 5. Мои биты

- открыть вкладку `Мои биты`
- показать, что новый бит появился
- показать поиск и сортировку

### 6. Редактирование бита

- открыть карточку собственного бита
- перейти в `Редактировать бит`
- изменить название, цену или описание
- сохранить изменения

### 7. Аналитика

- открыть экран аналитики бита
- показать:
  - прослушивания
  - лайки
  - покупки
  - выручку
- показать историю аналитики по дням
- нажать тестовые действия `Play / Like / Sale`
- показать изменение статистики

### 8. Проверка persistence

- перезапустить сервер
- снова открыть приложение
- показать, что:
  - профиль сохранился
  - биты сохранились
  - статистика не пропала
